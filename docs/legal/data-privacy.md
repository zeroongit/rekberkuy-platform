# Data Privacy & UU PDP Compliance — RekberKuy Platform

## 1. Overview
Dokumen ini menjelaskan bagaimana RekberKuy mengumpulkan, memproses, menyimpan, dan melindungi data pribadi pengguna sesuai dengan mandat **UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP)**.

## 2. Prinsip Pemrosesan Data Pribadi
1. **Transparansi:** Pengguna diberi tahu data apa saja yang dikumpulkan (nama, email, nomor HP, foto KTP, nomor rekening) dan tujuan penggunaannya.
2. **Batasan Tujuan:** Data hanya digunakan untuk verifikasi identitas (KYC), pemrosesan escrow, dan pencegahan penipuan.
3. **Keamanan Data:** Enkripsi data sensitif at-rest dan in-transit (TLS 1.3).

## 3. Hak Pengguna (Data Subject Rights)
- **Hak Akses:** Pengguna dapat meminta salinan data pribadi yang disimpan oleh platform.
- **Hak Koreksi:** Pengguna dapat mengajukan perbaikan data yang tidak akurat melalui menu pengaturan atau dukungan pelanggan.
- **Hak Penghapusan (Right to be Forgotten):** Akun dapat dinonaktifkan, dan data pribadi dianonimkan setelah masa retensi wajib hukum (5 tahun) berakhir.
- **Data Residency:** Seluruh server dan database utama disimpan di pusat data wilayah Indonesia.
